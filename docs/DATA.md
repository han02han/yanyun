## 二、公式（集中配置在 `src/data/formulas.ts`）

### 1. 五维换算（三个独立实现交叉一致：greydust / Phong940253 / WWM-METRICS）
| 五维 | 每点换算 |
|---|---|
| 劲 | 0.22 小外攻 + 1.36 大外攻 |
| 敏 | 0.9 小外攻 + 0.076% 会心率 |
| 势 | 0.9 大外攻 + 0.038% 会意率 |
| 体 | 60 气血（**PVE 不计入面板**） |
| 御 | 17 气血 + 0.57 外防（**PVE 不计入面板**） |

### 2. 白→黄三率（敌方"判定抵抗"）
- 装备/词条/五维加的都是**白字**，战斗生效的是**黄字**
- 黄精准 = 白 < 65% ? 白 : 65% + (白−65%)/1.65
- 黄会心 = 白会心/1.65；黄会意 = 白会意/1.65
- **直接会心/直接会意不衰减**（白=黄）
- 黄值上限：精准 100% / 会心 80% / 会意 40%；会心+会意 >100% 时按比例归一化
- ⚠️ 抵抗 0.65 = 突破 16/17（96-100 级）档，**110 级副本实际值待查**

### 3. 伤害公式（NGA 开服帖权威结构）
```
伤害 = [ (外功倍率×(外功攻击−防御)+固伤) ×(1+外功穿透/200)×(1+外伤加成)
      + (外功倍率×外系属攻) ×(1+属性穿透/200)×(1+属性伤加成)        ← 不减防御
      + (属性倍率×(本系属攻+80补正)) ×(1+属性穿透/200)×(1+属性伤加成) ← 不减防御 ]
      × 会意/会心倍率 × (1+增伤1+…+增伤n) × 特殊增伤 × (1+定音增伤)
```
- **防御只减外功部分**，属攻完全不减防御
- **穿透是独立乘区 (1+穿透/200)**，不是减防御
- **"本系额外 50% 倍率"** = 属性倍率 ≈ 外功倍率 × 1.5（NGA 帖原文 + 3 个社区实现一致；"大多是 1.5 倍"，非每技能精确值）
- **增伤全部加算**（唯一特殊增伤：绳标仇杀令，未建模）
- **四分支判定**（概率加权）：擦伤=最小攻 / 会意=最大攻×1.35×(1+会意伤) / 会心=平均攻×1.5×(1+会心伤) / 普通=平均攻
- **小外流**：外功小外 > 大外时，外功部分全部按小外结算（词条在临界点价值翻倍）
- **属攻同样有小外流规则**（玩家确认）：属攻小外 > 属攻大外时，属攻部分全部按属攻小外结算
- 属攻（含外系）同样按四分支结算；本系属攻 ×1.5 折算进面板，外系 ×1.0
- 本系 +80 补正（大世界9级+武学70级时代数值）**110 级待确认，未建模**
- MVP 简化：技能倍率固定 1、无技能循环、属性穿透用无相穿透近似

### 4. 承音 / 武库
- **承音**：词条上限 = 满值 × 0.94（如大外 121.4 → 114.12，玩家确认）
- **武库**（玩家确认）：通用武库 186 小外/373 大外；破竹/鸣金/牵丝/裂石武库同数值加对应属攻（本系 ×1.5 生效）

### 套装（10 种，选用制：选哪套生效哪套）
倾/撼/归/星/云 = 小外攻 +121；斗 = 大外攻 +121；烟/雨 = 精准 +12.5%；飞 = 会意 +7%；**断岳 = 效果数值待查**

### 词条优先级
- **神力（增伤）优先级很高**（玩家确认）：全武学增效 / 对首领单位增伤 / 指定与武器武学增效 优先洗
- 属攻价值：本系最大攻 > 外系最小攻 > 最大外攻 > 本系最小攻 ≈ 外系最大攻（NGA 建模帖排名）
- 收益排序仅供参考，不做机械推荐

### 调律生成规则（玩家确认）
- **第 1 条（主调律）有部位池限制**：
  - 武器1/2：大小外、大小无相、敏、势
  - 环/佩：大小外
  - 冠胄/胸甲：三率、气血、外防、体、御
  - 腕甲/胫甲：同头胸 + 劲
- **第 2-5 条**：从完整词条池洗入；**可与第 1 条重复**，但**彼此不能重复**

### 词条部位规则
- 武器1/2：无相、**只出本武器种类的武学增效**（剑只出剑增）；**无「武器增伤」词条**（玩家确认）
- 环/佩：全武学增效
- 冠胄/胸甲：单体类/群体类奇术增伤
- 胫甲/腕甲：对首领单位增伤、对玩家单位增效
- 六件（冠胸环佩胫腕）：属攻（大小破竹/鸣金/牵丝/裂石）
- 调律池含气血/防御（PVE 无用，数值占位）；体/御满值同劲敏势（76.8）
- 定音：左四件（武器1/2、环、佩）= 通用定音（穿透类）；右四件（冠胸胫腕）= 流派定音（技能增伤）
- **定音词条不出现在调律池**；**定音不受承音 ×0.94 限制**（可拉满）

## 四、毕业轴（11 流派）

- **目标属性** = 各流派计算器的满配轴默认面板（`reference/flow-inputs.json`），已转录为 `src/data/schools.ts` 的 `targetStats`
- **基线秒伤** = 计算器 `期望!I12 ADPS`（总伤÷战斗时间），`baselineDps`
- 六维：精准 / 会心 / 会意 / 外功（小外流取小外）/ 神力（全武学增效+首领增+指定与武器武学增效）/ 属攻
- **当前 DPS = 基线 × (当前单次期望 ÷ 轴单次期望)**（我们的简化模型用比例校准）
- ⚠️ 口径注意：
  - 基线含**默认心法 + 团队增益 + 食物**假设，换心法/团队会偏离
  - **牵丝霖是 15 秒爆发轴**，不可与其他流派横向比较
  - 各流派轴版本不同步（"表格需要等有轴才能更新"）
